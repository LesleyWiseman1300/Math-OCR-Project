📸 Math OCR with Gemini AI

An AI-powered Math OCR system that converts handwritten or printed mathematical equations from images into LaTeX, then solves and explains them step-by-step using Google Gemini AI. This project bridges computer vision and symbolic mathematics, making math accessible through image recognition.

🚀 Features

Image-to-LaTeX conversion using Pix2Tex

Automated math solving with Gemini AI

Step-by-step solution generation

Beautiful LaTeX rendering with MathJax

REST API built with Flask

Supports handwritten and printed math equations

Real-time results in the browser

🛠️ Tech Stack

Python (Flask, PyTorch)

Pix2Tex (LaTeX OCR)

Google Gemini API

JavaScript, HTML, CSS

MathJax for equation rendering

Students & educators
